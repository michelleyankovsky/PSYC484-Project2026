# PSYC484-Project2026
The study utilized an existing behavioral dataset from da Silva et al. (2021), which was originally collected to evaluate the APT model for risky decision-making. In the original study, participants completed a binary choice task involving decisions for monetary reward between a certain reward option ($1.00) and a risky reward option (>$1.00), with probability of either 0.9 or 0.5 of obtaining that reward. Due to the task involving repeated decisions, it provided the perfect dataset for examining whether current choices were influenced not only by the participants SV of the present option, but also if the immediately preceding choice influences the current trial. Rather than conducting a new experiment, this study reanalyzed previously collected data to test whether incorporation of recent choice history would better capture the data. This secondary analysis allows for comparison between the original APT model and the history-adapted component applied to the same dataset of observed choices.
